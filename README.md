# Шахтёр Hypixel

Android-приложение для отслеживания добытых блоков в Hypixel SkyBlock.

## Что умеет

- Показывает, сколько ты добыл по 25 «шахтёрским» коллекциям: булыжник, уголь, железо, алмазы, мифрил, самоцветы, глацит и другие.
- Считает общий итог и прирост за сегодня и за 7 дней.
- Рисует график по всем проверкам. Каждое нажатие «Обновить» сохраняет снимок на телефоне, если цифры изменились.
- Показывает порошок Heart of the Mountain: мифриловый, самоцветный и глацитовый.
- Позволяет переключаться между профилями SkyBlock.

## Что нужно один раз

1. **API-ключ.** Зайди на https://developer.hypixel.net, войди и создай ключ. Вставь его в настройках приложения (кнопка ⚙).
2. **Открытый доступ к коллекциям в игре.** SkyBlock Menu → Settings → API Settings → включи *Collections*.

## Как собрать APK

### Вариант А: на компьютере (Android Studio)
1. Установи Android Studio (бесплатно, developer.android.com/studio).
2. File → Open → выбери папку `HypixelMiner`. Подожди, пока Gradle всё скачает.
3. Подключи телефон по USB с включённой «Отладкой по USB» и нажми ▶ Run.
   Или: Build → Build APK(s) и скинь файл `app-debug.apk` на телефон.

### Вариант Б: без компьютера (GitHub)
1. Создай пустой репозиторий на github.com и загрузи туда все файлы из этой папки.
   Папку `.github` тоже: в ней лежит инструкция сборки.
2. Открой вкладку **Actions**. Сборка запустится сама и займёт 3–5 минут.
3. Открой готовый запуск и скачай **HypixelMiner-apk** внизу страницы. Распакуй zip и установи APK.
   Android попросит разрешить установку из этого источника.

## Как это работает

- Ник → UUID через API Mojang.
- Данные профиля: `GET https://api.hypixel.net/v2/skyblock/profiles?uuid=…` с заголовком `API-Key`.
- Числа — это значения коллекций (сколько предметов собрано добычей). С зачарованием Fortune они могут быть больше реального количества сломанных блоков.
- Сторонних библиотек нет, только стандартный Android SDK (minSdk 24, Android 7.0+).
